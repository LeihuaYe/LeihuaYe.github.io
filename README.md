# leihuaye.github.io

Personal site of Leihua Ye, built with Jekyll and served by GitHub Pages.

- Pages: `index.md`, `writing.md`, `tools.md`, `about.md`, `notes.html`
- Add a note: create `_notes/YYYY-MM-DD-slug.md` with front matter `title:` and `date:`, then push.
- Styles: `assets/style.css`. Layouts: `_layouts/`.
